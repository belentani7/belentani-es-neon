# Guía de Contribución

## Flujo de trabajo

1. Haz fork del repositorio y crea una rama `feat/nombre` o `fix/nombre`.
2. Usa [Conventional Commits](https://www.conventionalcommits.org): `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`.
3. Abre un Pull Request describiendo el cambio.
4. La CI debe pasar antes de mergear.

## Estándares

- Mantén el HTML semántico y accesible.
- Respeta `prefers-reduced-motion`.
- No añadas dependencias innecesarias (el sitio es vanilla).

## Reportar problemas

Abre un issue con la plantilla de bug o de feature.
