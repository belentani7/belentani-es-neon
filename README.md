# Belentani — Judas Era

Portfolio visual estático del universo Belentani.

## Qué es

La versión **estática y directa** de la obra: sin animación pesada, sin 3D, sin dependencias.
Carga rápido y se ve igual en cualquier dispositivo.

En línea: <https://belentani7.github.io/belentani-es-neon/>

## Estructura

```
index.html    portada
styles.css    identidad visual
main.js       interaccion minima
assets/       recursos
original/     version de referencia
```

## Identidad

Negro `#000000`, rojo neón `#ff073a`, dorado Zion `#d4af37`, cyan `#4de8e0`.
Orbitron para títulos, Share Tech Mono para el resto.
